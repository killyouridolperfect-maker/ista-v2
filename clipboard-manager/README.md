# クリップ帳（iPhone 対応 Web アプリ）

コピーした文字を履歴に残し、検索・編集・ワンタップで再コピーできる Web アプリ。インストール不要、アカウント不要。

## 使い方
- 「＋ 貼り付け」→ 出てきた「ペースト」で保存
- カードをタップ＝コピー / ☆ピン留め / 鉛筆で編集 / ゴミ箱で削除（元に戻す可）
- データはその端末のブラウザ内だけに保存。「バックアップを保存」で書き出し可能

## 背面タップで保存（iPhone）
`index.html?add=<URLエンコードした文字>` を開くと、その文字を保存して一覧を表示する。
ショートカット：「クリップボードを取得」→「URLエンコード」→「URLを開く」（`https://<公開URL>/index.html?add=` + エンコード結果）
設定 → アクセシビリティ → タッチ → 背面タップ → ダブルタップ に割り当てる。
